# Phase 0 Dogfood Findings — Codex × MSFT, full loop (2026-06-08)

Real run of the full loop with the OpenAI **Codex CLI** provider (gpt-5.5, ChatGPT subscription auth)
against a real ticker (**MSFT**) and a real holding (**10 shares @ $850**), in an isolated runtime
(`.data/dogfood-*`). Goal: measure whether the autonomous research is **investment-grade** before
building workstream A.

Research case: `rc_msft_1780940434686` (viewable at `http://127.0.0.1:3001/research/rc_msft_1780940434686`
while the dogfood dev server is up).

## TL;DR

The **plumbing is excellent; the brain is not investment-grade yet.** The full loop ran end to end and
produced a clean, fully-attributed 26-event audit trail. But the research engine is a single monolithic
structured LLM call with **tools disabled**, so it **fabricates sources and records them as if
verified** — the exact failure an investment-grade, grounded harness must prevent. This validates the
approved direction (workstream A) and sharpens its priorities.

## What worked (keep / don't touch)

- **Environment + Codex auth:** Codex CLI v0.137.0, `auth_mode: chatgpt`, detected ready via default
  `~/.codex/auth.json` (no env vars needed). Onboarding readiness gate passed for Codex.
- **End-to-end workflow + ledger:** every transition recorded with correct actor attribution and a clean
  causation chain (26 events): `research_case_created (user)` → 7× `specialist_finding_recorded (provider)`
  → `deep_dive_synthesis/completed (system)` → `buffett_munger_analysis_drafted (provider)` →
  `decision_drafted (system)` → `shariah_evaluation`+`shariah_gate_decision` at **each** transition →
  `watchlist_draft_created/confirmed (user)` → `holding_opened (user)` → `holding_valuation_recorded (user)`.
- **Shariah gating** fires on promotion, confirmation, and holding-open — good human-in-the-loop discipline.
- **Prose quality** of the analysis is high: verdict **WATCH**, Shariah **CONDITIONAL**, valuation
  **EXPENSIVE**; thesis reads like a real Buffett-Munger brief (moat = switching costs/ecosystem/scale).
- **Pages** `/portfolio`, `/accounting/monthly`, `/audit` render the holding (200, MSFT present).

## What's broken / not investment-grade (workstream A — the core)

1. **Grounding invariant violated — fabricated sources recorded as verified.** The research request sets
   `budget.max_tool_calls: 0` and `tool_allowlist: []` (in `packages/workflow/src/claudeResearchWorkflow.ts`
   `buildRequest`), yet the schema requires `source_records` with valid URLs. The model invents them.
   The captured bundle (`data/source-ledger/research-source-bundle-rc_msft_1780940434686.json`) marks each
   as `availability: "available"`, `ingested_by_actor: research_workflow` — i.e. *as if fetched* — with
   precise figures it never verified (e.g. "Q3 FY26 ending March 31 2026 revenue $82.9B", "capex ~$190B",
   "market cap $3.07T as of May 27 2026"). Several are forward of reliable knowledge → almost certainly
   fabricated. **This is the central trust defect.**
2. **No autonomy.** "Autonomous research" today = one structured prompt asking the model to fill a big
   schema from memory. Tools/web are explicitly off; nothing is gathered. The user's requirement
   ("the AI gathers its own evidence, no hand-feeding") is not met.
3. **Single monolithic call, not a strategy-driven multi-lane pipeline.** `runClaudeBuffettMungerResearch`
   makes ONE `provider.structured(...)` call and then *fans the single response out* into 7
   `specialist_finding_recorded` events. The real per-lane pipeline (`strategyResearchPipeline.ts`) is
   not what the web path runs. So the "7 specialists" are presentational, not independent analyses.
4. **Timeout mis-tuned (marginal).** `timeout_ms: 120_000`; the call genuinely needs ~80s and varies over
   120s. First app run failed at 120s; retry succeeded at 80.2s; a direct 300s-cap probe completed in
   81.8s. Easy to raise, but a band-aid — re-architecting to grounded multi-step is the real fix.

## Supporting-cast findings (workstreams B / C / housekeeping)

- **C (prices):** confirmed there is no real price path — I had to hand-enter $415; the valuation event
  records `valuation_source: manual`, `confidence: ""`. The clean swap seam (`mockPriceForHolding` in
  `apps/worker/src/runtime.ts`) is still the right target.
- **Accounting/Purification:** no `accounting_snapshot_recorded` is auto-generated by the loop, and
  `/purification` shows nothing for MSFT (needs dividend events). Purification is only meaningful once
  dividends + snapshots exist — flag for the "real use" path.
- **B / API hygiene:** `/api/watchlist/[id]/open-holding` and `/valuation` require form-encoding while
  `/api/research/start` and `/onboarding/start` take JSON — inconsistent; cost me a 500 first try.
  `/watchlist` promotion and `confirm` return 307/303 redirects (browser-form oriented, not API-clean).
- **Isolation bug:** `OWLFOLIO_SOURCE_LEDGER_PATH` override was ignored by `initializeSelectedMode`
  (source bundle wrote to default `data/source-ledger`, not `.data/dogfood-source-ledger`).

## Scorecard vs the investment-grade bar

| Dimension | Verdict |
|---|---|
| Autonomy (gathers own evidence) | ❌ tools disabled; nothing gathered |
| Grounding (no claim without a captured source) | ❌ sources fabricated, recorded as verified |
| Strategy-fit (strategy drives the research) | ⚠️ one prompt mentions lanes; not truly lane-driven |
| Depth / prose quality | ✅ genuinely strong narrative |
| Auditability of the *pipeline* | ✅ excellent ledger + actor attribution |

## Re-prioritized next steps

1. **A1 — Grounding first (highest):** enable real evidence-gathering for Codex (lift `--sandbox
   read-only` / give a fetch tool), and make the harness **reject/flag any `source_id` not backed by a
   genuinely fetched, content-hashed source.** Stop recording fabricated sources as `available`.
   Until grounded, mark provider sources `unverified` rather than `available`.
2. **A2 — Re-architect research to grounded multi-step** (gather → per-lane analysis → synthesis),
   making the strategy contract actually drive lanes; raise/flex the timeout as part of this.
3. **A3 — Formalize the trust contract in `certificationRunner.ts`** and re-certify Codex against it
   (the `source-grounded-research-task` becomes the central gate).
4. **C — real price adapter** behind `getPriceForHolding()` (clean, low-risk).
5. **B — onboarding/provider connect polish** + API hygiene (form-vs-JSON, redirects).
6. Housekeeping: fix the `OWLFOLIO_SOURCE_LEDGER_PATH` override; auto/scheduled accounting snapshot.
